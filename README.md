# Recall: F-Droid repository

Signed releases of Recall, NJ's personal flashcard app, published as an F-Droid
repository. This repository holds only the signed APKs and the F-Droid index;
the app's source code is private.

Add it in the F-Droid app (Settings → Repositories → +) with this address,
which carries the repository key's fingerprint:

```
https://raw.githubusercontent.com/AndrzejMnM/recall-fdroid/main/repo?fingerprint=9CD390DAE3C7B165168E2691747EBCADF1523AFCED27643A93E8421685ED6FAF
```

- Repository signing key (SHA-256): `9CD390DAE3C7B165168E2691747EBCADF1523AFCED27643A93E8421685ED6FAF`
- App signing certificate (SHA-256): `8a1c603bce83a05ddf83bc03ba87d579d741823340bebaaea3c0de6fd35d899c`

The app needs a private setup code to connect to its data, so it is of no use
to anyone else.
